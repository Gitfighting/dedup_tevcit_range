# PolicyMilpECnew V1 / V2 / V3 与 Tevictranges（PolicyTevictRangesNew）对比

本文档对比三套 MILP-EC 策略与基线 **`PolicyTevictRangesNew`** 在代码层面的差异，并汇总 **`java_result/All_Results.csv`** 中的仿真结果。**每条实验行均标注 CSV 中的 `tag_month_day` 与 `timestamp`（仿真产出时间），便于核对版本与复现实验。**

---

## 1. 命名与源码对应

| 简称 | Java 类 | `All_Results.csv` 中 `policy` 字段（本表数据中出现的） |
|------|---------|--------------------------------------------------------|
| **基线 PF** | `PolicyTevictRangesNew`（Placement-Follow 配置） | `tevictranges_pf` |
| **基线 FB** | `PolicyTevictRangesNew`（Fixed-Base 配置） | `tevictranges_fb` |
| **V1** | `PolicyMilpECnew` | `milp_ec_new_pf`（表中仅有 PF 跑批；**无** `milp_ec_new_fb` 行） |
| **V2** | `PolicyMilpECnewV2` | `milp_ec_new_v2_fb` |
| **V3** | `PolicyMilpECnewV3` | **当前 CSV 中无对应 `policy` 行**（若已跑仿真，需追加汇总） |

---

## 2. 代码逻辑要点（与 Tevictranges 的关系）

| 维度 | V1 `PolicyMilpECnew` | V2 `PolicyMilpECnewV2` | V3 `PolicyMilpECnewV3` |
|------|----------------------|------------------------|-------------------------|
| 与 `PolicyTevictRangesNew` | **继承**，直方图/TTL 走父类 | **不继承**，类内自实现同款直方图/TTL | **不继承**，直方图/TTL 拷贝为独立实现 |
| EC 形态 | RS(2,1)，**3 片** | EC(2,0)，**2 片**；第二片落点可 **贪心**（边权最小） | EC(2,1)，**3 片** + slot；**FB** 基底整副本 |
| MILP 触发 | 窗口内按 region 聚合流量，批量求解 | 同左（窗口/事件阈值） | **按 region 节流**（如每 1 小时桶），可读 miss **按需求解** |
| TTL / 驱逐 | EC TTL 与 MILP `hatTau` 等衔接；继承父类驱逐 | 自定义 `canEvict` / 联动驱逐等 | `getTevict` 走 region 对 TTL；与 Simulator 严格对齐 |

更细的公式与约束见：`docs/PolicyMilpECnewV2_Design.md`、`docs/PolicyMilpECnewV3_Design.md`。

## 3. 实验数据来源与字段说明

- **文件**：`java_result/All_Results.csv`
- **列含义（本节用到的）**：`policy`，`regions`，`trace`，`total_cost`，`tag_month_day`，`timestamp`
- **`timestamp` 格式**：`YYYYMMDD_HHMMSS`（CSV 最后一列），表示该条结果写入/仿真结束时间。
- **对比注意**：
  - **PF 对比**：V1 使用 `milp_ec_new_pf`，基线使用 `tevictranges_pf`；**不同 `tag_month_day` 时成本不可严格横向归因于算法 alone**（配置或代码版本可能不同），但时间戳可用于追溯。
  - **FB 对比**：V2 使用 `milp_ec_new_v2_fb`，基线使用 `tevictranges_fb`；下表 **9reg / 6reg / 3reg** 在可能时选用 **同日 `0317`** 的 FB 行与 V2 对齐。
